## Особенности интерфейса

### 1. Эмодзи для наглядности
- 💰 Финансы, баланс
- 📋 Документы, путевые листы
- 🚗 Автомобиль
- 👤 Водитель
- ✅ Успех
- ❌ Ошибка
- ⚠️ Предупреждение
- 📞 Контакты
- 📏 Пробег
- ⏳ Загрузка

### 2. Цветовое кодирование (в PDF)
- **Зелёный** - медицинский контроль
- **Оранжевый** - технический контроль
- **Красный** - разрешение на выезд
- **Фиолетовый градиент** - показания одометра

### 3. Валидация ввода
- Проверка формата пробега
- Предупреждение при низком пробеге
- Проверка баланса перед созданием ПЛ
- Проверка авторизации для всех команд

### 4. Обратная связь
- Немедленное подтверждение действий
- Информативные сообщения об ошибках
- Подробная история операций
- Контекстная помощь

### 5. Удобство использования
- Персистентная клавиатура (всегда видна)
- Минимум ввода текста
- Максимум кнопок
- Интуитивная навигация

## Адаптация интерфейса

Интерфейс можно адаптировать под ваши нужды:

### Изменение текстов
Файлы: `bot/handlers/auth_handler.py`, `bot/handlers/main_handler.py`

### Изменение шаблона ПЛ
Файл: `bot/templates/waybill.html`

### Добавление новых команд
1. Создать handler
2. Добавить кнопку в клавиатуру
3. Зарегистрировать в main.py

### Изменение логики
Файлы в `bot/services/`

---

**Примечание**: Все тексты и сообщения на русском языке. При необходимости можно добавить поддержку других языков.
