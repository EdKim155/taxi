# Часто задаваемые вопросы (FAQ)

## Общие вопросы

### Что такое путевой лист?

Путевой лист - это обязательный документ для транспортных средств, который подтверждает допуск водителя и автомобиля к работе. Он содержит информацию о водителе, транспортном средстве, медицинском и техническом осмотре.

### Сколько стоит путевой лист?

По умолчанию каждый путевой лист стоит **20 ₽**. Эта сумма автоматически списывается с баланса водителя при формировании ПЛ. Цена может быть изменена администратором индивидуально для каждого водителя.

### Как часто нужно получать путевой лист?

Обычно путевой лист выдается на одну смену (рабочий день). Водитель получает новый ПЛ каждый раз при выезде на линию.

## Авторизация

### Бот не принимает мой номер телефона

**Причины:**
1. Ваш номер не добавлен в базу водителей
2. Номер в базе указан в другом формате

**Решение:**
- Обратитесь к администратору
- Убедитесь, что номер в базе указан в формате `+7XXXXXXXXXX`
- Проверьте, что ваш аккаунт активен (`is_active = TRUE`)

### Бот пишет "Вы не авторизованы"

**Причины:**
1. Вы не прошли авторизацию через кнопку "Поделиться номером"
2. Ваш аккаунт был деактивирован

**Решение:**
- Отправьте команду `/start` и пройдите авторизацию заново
- Свяжитесь с администратором для проверки статуса аккаунта

### Можно ли использовать бот с нескольких устройств?

Да, Telegram позволяет использовать один аккаунт на нескольких устройствах. Бот будет работать на всех устройствах, где вы авторизованы в Telegram.

## Баланс и оплата

### Как пополнить баланс?

**В текущей версии (MVP):**
1. Переведите деньги на реквизиты таксопарка
2. Сообщите администратору о пополнении
3. Администратор вручную зачислит средства на ваш баланс

**В будущих версиях:**
Планируется автоматическое пополнение через банковские карты.

### Что делать, если баланс отрицательный?

Бот не позволит создать путевой лист при отрицательном или недостаточном балансе. Пополните баланс через администратора.

### Можно ли получить возврат средств?

Вопросы возврата средств решаются с администратором таксопарка в индивидуальном порядке.

### Где посмотреть историю операций?

Нажмите кнопку **"💰 Мой баланс"** в главном меню. Бот покажет текущий баланс и последние 3 операции.

## Получение путевого листа

### Бот не принимает мои показания одометра

**Причины:**
1. Введено не число (например, текст или символы)
2. Введено отрицательное число или ноль

**Решение:**
- Введите только число, без пробелов и букв
- Пример: `150000` (а не `150 000` или `150000км`)

### Почему бот просит подтверждение при вводе пробега?

Бот показывает предупреждение, если введённый пробег **меньше** предыдущего зафиксированного пробега. Это защита от ошибок ввода.

**Если пробег действительно уменьшился** (например, заменили панель приборов):
- Подтвердите создание ПЛ кнопкой "✅ Да, продолжить"
- Или свяжитесь с администратором для корректировки базового пробега

### Что такое "коррекция одометра"?

Некоторые автомобили могут иметь неточные показания одометра. Администратор может настроить коррекцию, которая автоматически вычитается из введённого пробега.

**Пример:**
- Одометр "врёт" на +27 км
- Вы вводите: 120200 км
- В путевом листе будет: 120173 км

### Время в путевом листе не совпадает с реальным

Это **нормально**. По требованиям заказчика, время в ПЛ отображается на **1 час раньше** фактического времени запроса. Это сделано для имитации "получения ПЛ час назад".

**Пример:**
- Вы запросили ПЛ в 13:00
- В документе будет указано 12:00

### Не получил PDF файл

**Причины:**
1. Недостаточно средств на балансе
2. Техническая ошибка генерации

**Решение:**
- Проверьте баланс командой **"💰 Мой баланс"**
- Попробуйте создать ПЛ снова через 1-2 минуты
- Если проблема повторяется, свяжитесь с администратором

### Можно ли получить копию старого путевого листа?

В текущей версии бот не сохраняет доступ к старым ПЛ. Однако администратор может найти файл в папке `generated_waybills` на сервере или посмотреть запись в журнале Google Sheets.

### Путевой лист не открывается на телефоне

**Решение:**
1. Установите приложение для просмотра PDF (например, Adobe Acrobat Reader)
2. Скачайте файл и откройте через файловый менеджер
3. Попробуйте открыть в браузере

## Для администраторов

### Как добавить нового водителя?

1. Откройте Google таблицу
2. Перейдите на лист `drivers`
3. Добавьте новую строку с данными:
   - `driver_id` - уникальный ID (например, DRV003)
   - `fio` - полное ФИО
   - `phone` - в формате +7XXXXXXXXXX
   - `car_plate`, `car_model` - данные автомобиля
   - `balance` - начальный баланс
   - `is_active` - TRUE

### Как деактивировать водителя?

В листе `drivers` измените значение `is_active` на FALSE. Водитель больше не сможет использовать бота.

### Как изменить цену путевого листа?

**Для всех водителей:**
Лист `settings`, параметр `pl_price_default`

**Для конкретного водителя:**
Лист `drivers`, колонка `pl_price`

### Как исправить пробег водителя?

В листе `drivers` измените значение `last_odo` на правильное.

### Как настроить коррекцию одометра?

В листе `drivers` установите значение `odo_delta` (в километрах). Это значение будет вычитаться из введённого пробега.

### Где посмотреть все выданные путевые листы?

Все путевые листы записываются в лист `waybills` с полной информацией:
- Номер ПЛ
- Время создания
- Водитель
- Пробег
- Списанная сумма

### Где хранятся PDF файлы?

На сервере в папке `generated_waybills/`. Название файла содержит номер ПЛ и дату.

### Можно ли изменить шаблон путевого листа?

Да, шаблон находится в файле `bot/templates/waybill.html`. Вы можете изменять HTML и CSS по своему усмотрению.

### Как сделать резервную копию данных?

**Google Sheets:**
- File → Download → .xlsx или .csv
- Или настройте автоматический экспорт через Google Takeout

**PDF файлы:**
- Скопируйте папку `generated_waybills` на другой носитель
- Настройте автоматический backup через cron (см. DEPLOYMENT.md)

### Бот перестал отвечать

**Проверка:**
```bash
# Для systemd
sudo systemctl status taxi-waybill-bot

# Для Docker
docker ps
docker logs taxi-waybill-bot
```

**Перезапуск:**
```bash
# Для systemd
sudo systemctl restart taxi-waybill-bot

# Для Docker
docker-compose restart
```

### Как посмотреть логи бота?

**Для systemd:**
```bash
sudo journalctl -u taxi-waybill-bot -f
# или
tail -f /var/log/taxi-waybill-bot/output.log
```

**Для Docker:**
```bash
docker-compose logs -f
```

## Технические вопросы

### Какие данные хранятся в Google Sheets?

- **drivers** - справочник водителей и автомобилей
- **waybills** - журнал всех путевых листов
- **transactions** - история финансовых операций
- **settings** - настройки системы

### Безопасны ли мои данные?

Да:
- Доступ к Google таблице только у сервисного аккаунта и администраторов
- Telegram передает данные по зашифрованному каналу
- Сервер защищен firewall и SSL
- Конфиденциальные файлы имеют ограниченные права доступа

### Что делать при технических проблемах?

1. Перезапустите бота командой `/start`
2. Проверьте баланс и статус аккаунта
3. Попробуйте через 5-10 минут
4. Обратитесь к администратору
5. Администратор может проверить логи сервера

### Какие требования к серверу?

Минимальные:
- 512 MB RAM (рекомендуется 1 GB)
- 1 CPU core
- 5 GB дискового пространства
- Ubuntu 20.04+ или Debian 11+

### Можно ли запустить бот на Windows?

Теоретически да, но рекомендуется Linux сервер для production. Для тестирования на Windows:
1. Установите Python 3.10+
2. Установите зависимости WeasyPrint может потребовать дополнительных библиотек
3. Используйте Git Bash или WSL

### Поддерживает ли бот несколько языков?

В текущей версии только русский язык. При необходимости можно добавить поддержку других языков.

### Можно ли интегрировать с другими системами?

Да, архитектура бота позволяет расширение:
- API для внешних систем
- Webhook для уведомлений
- Интеграция с 1С, CRM и т.д.

### Планируются ли новые функции?

Возможные расширения:
- Автоматическое пополнение через эквайринг
- Мобильное приложение
- Фотографии автомобиля в ПЛ
- Электронная подпись
- Интеграция с GPS трекерами
- Статистика и аналитика
