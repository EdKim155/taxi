## 🎯 Что реализовано

### ✅ Основной функционал

1. **Telegram Bot**
   - Авторизация по номеру телефона
   - Персистентное меню с кнопками
   - Conversation handlers для диалогов
   - Валидация пользовательского ввода
   - Обработка ошибок

2. **Генерация путевых листов**
   - Красивый HTML/CSS шаблон
   - Конвертация в PDF через WeasyPrint
   - QR-код для проверки подлинности
   - Градиентные блоки, цветовое кодирование
   - Информативные секции (водитель, авто, контроль)

3. **Система балансов**
   - Автоматическое списание 20₽ за ПЛ
   - История транзакций
   - Проверка баланса перед созданием ПЛ
   - Поддержка пополнения (вручную)

4. **Интеграция с Google Sheets**
   - 4 листа: drivers, waybills, transactions, settings
   - CRUD операции
   - Кэширование worksheets
   - Batch operations

5. **Бизнес-логика**
   - Коррекция одометра (odo_delta)
   - Валидация пробега
   - Сдвиг времени -1 час в ПЛ
   - Поддержка часовых поясов
   - Нумерация ПЛ (76-YYYYMM-NNNN)
   - Настраиваемые параметры
