## Описание элементов

### Заголовок
- **Название документа**: крупным шрифтом, выделен
- **Номер ПЛ**: красным цветом, хорошо заметен
- **Дата**: время из ПЛ (dt_print)
- **Статус**: зеленая метка "ДЕЙСТВИТЕЛЕН"

### Секция "Сведения об организации"
- Название организации или ИП
- Может содержать адрес и реквизиты (при расширении)

### Секция "Сведения о водителе"
- ФИО водителя
- Контактный телефон
- ID водителя (для внутреннего учета)
- Возможно добавление: номер водительского удостоверения, категория

### Секция "Сведения о транспортном средстве"
- Марка и модель автомобиля
- Государственный регистрационный знак (выделен)
- VIN номер
- Возможно добавление: год выпуска, цвет

### Показания одометра
- Крупно выделенный блок с градиентным фоном
- Показания после коррекции (если применяется)
- Примечание о коррекции (если odo_delta != 0)

### Контрольные отметки
Три блока с цветовым кодированием:
1. **Медицинский контроль** (зеленая линия)
   - ФИО медработника
   - Время осмотра (dt_print)

2. **Технический контроль** (оранжевая линия)
   - ФИО механика
   - Время осмотра (dt_print)

3. **Разрешён выезд** (красная линия)
   - Диспетчер
   - Время разрешения (dt_print)

### QR-код
- Содержит информацию для проверки подлинности:
  - Номер путевого листа
  - Дата и время
  - Показания одометра
- Может использоваться для автоматической проверки инспекторами

### Подвал
- Информация о системе генерации
- Фактическое время формирования (для служебного использования)

## Цветовая схема

### Основные цвета:
- **Заголовок**: темно-синий (#2c3e50)
- **Номер ПЛ**: красный (#e74c3c)
- **Статус "Действителен"**: зеленый (#27ae60)
- **Одометр**: градиент фиолетовый (#667eea → #764ba2)
- **Медконтроль**: светло-зеленый (#27ae60)
- **Техконтроль**: оранжевый (#f39c12)
- **Выезд**: красный (#e74c3c)

### Фон:
- Секции: светло-серый (#f9f9f9)
- Четные строки: белый (#fff)
- Общий фон: белый

## Особенности дизайна

1. **Адаптивность**: макет оптимизирован для печати на A4
2. **Читаемость**: четкие разделители между секциями
3. **Информативность**: все необходимые данные на одной странице
4. **Профессиональный вид**: градиенты, иконки, цветовое кодирование
5. **Защита**: QR-код для проверки подлинности

## Время в путевом листе

⚠️ **Важная особенность**: 

Если водитель запрашивает ПЛ в **13:00**, то в документе будет указано **12:00** (сдвиг на 1 час назад).

Это сделано согласно требованиям заказчика, чтобы путевой лист выглядел как "полученный час назад".

## Формат файла

- **Формат**: PDF
- **Размер**: A4 (210 × 297 мм)
- **Ориентация**: Portrait (вертикальная)
- **Размер файла**: ~50-100 KB
- **Название файла**: `waybill_76_202401_0001_20240101_130000.pdf`

## Настройка шаблона

Шаблон находится в файле `bot/templates/waybill.html` и может быть легко изменен:

### Добавление полей:
1. Откройте `bot/templates/waybill.html`
2. Добавьте новый блок в нужном месте
3. Используйте переменные Jinja2: `{{ имя_переменной }}`
4. Добавьте передачу данных в `bot/services/pdf_service.py`

### Изменение стилей:
1. Найдите секцию `<style>` в шаблоне
2. Измените CSS классы по вашему желанию
3. Можете использовать любые CSS свойства, поддерживаемые WeasyPrint

### Добавление логотипа:
```html
<div class="header">
    <img src="путь_к_логотипу.png" alt="Logo" style="height: 50px;">
    <h1>ПУТЕВОЙ ЛИСТ ЛЕГКОВОГО АВТОМОБИЛЯ</h1>
    ...
</div>
```

### Пример добавления фото водителя:
```html
<div class="section">
    <div class="section-title">👤 СВЕДЕНИЯ О ВОДИТЕЛЕ</div>
    {% if driver_photo %}
    <img src="{{ driver_photo }}" alt="Фото водителя" style="width: 100px; float: right;">
    {% endif %}
    <div class="info-row">
        <div class="info-label">ФИО:</div>
        <div class="info-value">{{ driver_fio }}</div>
    </div>
    ...
</div>
```

## Примеры использования

### Кейс 1: Стандартный путевой лист
```
Водитель: Иванов И.И.
Пробег: 100500 км
Коррекция: 0 км
Результат: в ПЛ указано 100500 км
```

### Кейс 2: С коррекцией одометра
```
Водитель: Петров П.П.
Пробег: 120200 км
Коррекция: 27 км
Результат: в ПЛ указано 120173 км
+ показано примечание о коррекции
```

### Кейс 3: Пробег меньше предыдущего
```
Водитель: Сидоров С.С.
Предыдущий пробег: 95000 км
Введенный пробег: 90000 км
Действие: бот запросит подтверждение
Результат: после подтверждения создаст ПЛ с пробегом 90000 км
```

## Расширения шаблона (идеи)

Вы можете расширить шаблон следующими элементами:

1. **Штрих-код** (дополнительно к QR)
2. **Фотография водителя**
3. **Логотип компании**
4. **Подпись водителя** (цифровая)
5. **График работы** (плановое время смены)
6. **Маршрут** (если известен)
7. **Данные лицензии такси**
8. **Информация о страховке**
9. **Контакты диспетчерской**
10. **Водяной знак** (для защиты от копирования)

## Совместимость

Сгенерированный PDF совместим с:
- ✅ Adobe Acrobat Reader
- ✅ Foxit Reader
- ✅ Браузеры (Chrome, Firefox, Safari, Edge)
- ✅ Мобильные приложения для просмотра PDF
- ✅ Печать на любом принтере

## Печать

При печати:
- Используйте бумагу A4
- Рекомендуемая ориентация: Portrait
- Цветная или черно-белая печать (дизайн адаптирован для обоих вариантов)
- Масштаб: 100% (без подгонки)
