# Changelog

Все важные изменения в проекте будут документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект следует [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] - 2024-01-01

### Добавлено
- 🎉 Первый релиз Taxi Waybill Bot
- ✅ Авторизация водителей по номеру телефона
- 📄 Генерация PDF путевых листов с красивым шаблоном
- 💰 Система учета балансов водителей
- 📊 Автоматическое списание 20₽ за каждый путевой лист
- 🔄 Интеграция с Google Sheets для хранения данных
- ⏰ Автоматический сдвиг времени на -1 час в путевых листах
- 🔧 Коррекция одометра (odo_delta)
- 🌍 Поддержка часовых поясов
- 📱 QR-код на путевом листе для проверки подлинности
- 📝 История транзакций (последние 3 операции)
- ⚠️ Валидация пробега (предупреждение если меньше предыдущего)
- 🔐 Проверка баланса перед созданием ПЛ
- 📋 Журналирование всех операций в Google Sheets
- 🎨 Современный дизайн путевого листа с цветовым кодированием
- 📦 Поддержка Docker и systemd для развертывания
- 📚 Подробная документация (README, DEPLOYMENT, FAQ)
- 🛠️ Скрипт автоматической настройки (setup.sh)

### Структура проекта
- `bot/handlers/` - обработчики Telegram команд
- `bot/services/` - бизнес-логика (sheets, pdf, transactions, waybill)
- `bot/templates/` - HTML шаблон для PDF
- `config.py` - конфигурация приложения
- `main.py` - точка входа

### Google Sheets структура
- **drivers** - справочник водителей и автомобилей
- **waybills** - журнал путевых листов
- **transactions** - история финансовых операций
- **settings** - настройки системы

### Технологии
- Python 3.10+
- python-telegram-bot 20.7
- Google Sheets API (gspread)
- WeasyPrint + Jinja2 для PDF
- pytz для работы с часовыми поясами
- qrcode для генерации QR-кодов

### Команды бота
- `/start` - авторизация и начало работы
- `/help` - справка
- `💰 Мой баланс` - просмотр баланса и истории
- `📋 Получить путевой лист` - создание нового ПЛ
- `❓ Помощь` - контакты поддержки

### Документация
- `README.md` - основная документация
- `DEPLOYMENT.md` - руководство по развертыванию
- `FAQ.md` - часто задаваемые вопросы
- `GOOGLE_SHEETS_TEMPLATE.md` - структура Google таблицы
- `WAYBILL_TEMPLATE_EXAMPLE.md` - описание шаблона ПЛ
- `CHANGELOG.md` - история изменений

### Конфигурация
- `.env.example` - пример конфигурации
- `requirements.txt` - зависимости Python
- `Dockerfile` - Docker образ
- `docker-compose.yml` - Docker Compose конфигурация
- `taxi-waybill-bot.service` - systemd service файл
