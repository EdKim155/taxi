# Шаблон структуры Google Sheets

Этот документ содержит подробное описание структуры Google таблицы для бота путевых листов.

## Создание таблицы

1. Создайте новую Google таблицу
2. Создайте 4 листа (вкладки) с названиями: `drivers`, `waybills`, `transactions`, `settings`
3. Заполните заголовки согласно структуре ниже

---

## Лист 1: `drivers`

### Заголовки (первая строка):

| A | B | C | D | E | F | G | H | I | J | K | L | M | N | O | P | Q |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| driver_id | fio | phone | tg_user_id | car_id | car_plate | car_model | vin | org_name | med_worker | mech_worker | last_odo | odo_delta | balance | pl_price | tz | is_active |

### Описание полей:

- **driver_id** (string): Уникальный ID водителя (например: DRV001)
- **fio** (string): Полное ФИО водителя
- **phone** (string): Телефон в формате +7XXXXXXXXXX
- **tg_user_id** (number): ID пользователя в Telegram (заполняется ботом автоматически)
- **car_id** (string): ID автомобиля (для связи, если есть отдельная таблица cars)
- **car_plate** (string): Государственный регистрационный знак (ГРЗ)
- **car_model** (string): Марка и модель автомобиля
- **vin** (string): VIN номер автомобиля
- **org_name** (string): Название организации/ИП для путевого листа
- **med_worker** (string): ФИО медицинского работника
- **mech_worker** (string): ФИО механика
- **last_odo** (number): Последние зафиксированные показания одометра (км)
- **odo_delta** (number): Коррекция одометра (вычитается из введенного значения)
- **balance** (number): Текущий баланс водителя (₽)
- **pl_price** (number): Индивидуальная цена путевого листа (₽)
- **tz** (string): Часовой пояс (например: Europe/Moscow)
- **is_active** (boolean): TRUE/FALSE - активен ли водитель

### Пример данных:

| driver_id | fio | phone | tg_user_id | car_id | car_plate | car_model | vin | org_name | med_worker | mech_worker | last_odo | odo_delta | balance | pl_price | tz | is_active |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| DRV001 | Иванов Иван Иванович | +79991234567 | | CAR001 | А123БВ777 | Toyota Camry | 1HGBH41JXMN109186 | ИП Михайлов М.М. | Петрова А.С. | Сидоров П.И. | 100000 | 0 | 1000 | 20 | Europe/Moscow | TRUE |
| DRV002 | Петров Петр Петрович | +79991234568 | | CAR002 | В456ГД777 | Hyundai Solaris | 2T3BF4DV5BW123456 | ИП Михайлов М.М. | Петрова А.С. | Сидоров П.И. | 85000 | 27 | 500 | 20 | Europe/Moscow | TRUE |

## Лист 2: `waybills`

### Заголовки (первая строка):

| A | B | C | D | E | F | G | H | I | J | K | L | M |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| wb_id | wb_number | dt_fact | dt_print | driver_id | car_plate | odo_input | odo_effective | price | balance_after | pdf_url | status | error |

### Описание полей:

- **wb_id** (string): Уникальный ID путевого листа (генерируется автоматически)
- **wb_number** (string): Номер путевого листа (например: 76-202401-0001)
- **dt_fact** (datetime): Фактическое время создания ПЛ
- **dt_print** (datetime): Время, указанное в ПЛ (dt_fact - 1 час)
- **driver_id** (string): ID водителя
- **car_plate** (string): ГРЗ (снимок на момент создания ПЛ)
- **odo_input** (number): Показания одометра, введенные водителем (км)
- **odo_effective** (number): Показания одометра в ПЛ после применения коррекции (км)
- **price** (number): Сумма списания (₽)
- **balance_after** (number): Баланс водителя после списания (₽)
- **pdf_url** (string): Имя файла PDF или ссылка на него
- **status** (string): ok/error - статус генерации
- **error** (string): Текст ошибки (если есть)

### Пример данных:

Эти данные будут заполняться ботом автоматически при создании путевых листов.

## Лист 3: `transactions`

### Заголовки (первая строка):

| A | B | C | D | E | F | G |
|---|---|---|---|---|---|---|
| tx_id | dt | driver_id | type | amount | reason | balance_after |

### Описание полей:

- **tx_id** (string): Уникальный ID транзакции
- **dt** (datetime): Дата и время операции
- **driver_id** (string): ID водителя
- **type** (string): topup (пополнение) / debit (списание)
- **amount** (number): Сумма операции (₽)
- **reason** (string): Описание операции
- **balance_after** (number): Баланс после операции (₽)

### Пример данных:

| tx_id | dt | driver_id | type | amount | reason | balance_after |
|---|---|---|---|---|---|---|
| TX-20240101120000 | 2024-01-01 12:00:00 | DRV001 | topup | 1000 | Пополнение администратором | 1000 |
| TX-20240101130000 | 2024-01-01 13:00:00 | DRV001 | debit | 20 | ПЛ №76-202401-0001 | 980 |

## Лист 4: `settings`

### Заголовки (первая строка):

| A | B |
|---|---|
| parameter | value |

### Обязательные параметры:

| parameter | value | Описание |
|---|---|---|
| pl_price_default | 20 | Стоимость путевого листа по умолчанию (₽) |
| tz_default | Europe/Moscow | Часовой пояс по умолчанию |
| time_shift_minutes | 60 | Сдвиг времени в ПЛ (минуты) |
| apply_odo_delta | true | Применять ли коррекцию одометра (true/false) |
| update_last_odo_with | input | Что записывать в last_odo: input или effective |

### Пример заполнения:

| parameter | value |
|---|---|
| pl_price_default | 20 |
| tz_default | Europe/Moscow |
| time_shift_minutes | 60 |
| apply_odo_delta | true |
| update_last_odo_with | input |

## Права доступа

После создания таблицы:

1. Откройте файл `service_account.json`
2. Найдите поле `client_email` (формат: `название@проект.iam.gserviceaccount.com`)
3. Нажмите "Настройки доступа" (Share) в Google Sheets
4. Добавьте этот email с правами **Редактор**

---

## Типы данных

При вводе данных в Google Sheets обратите внимание на типы:

- **Текст**: обычный ввод
- **Число**: вводите без пробелов и специальных символов
- **Дата/время**: формат `YYYY-MM-DD HH:MM:SS` (например: 2024-01-01 12:00:00)
- **Булево**: TRUE или FALSE (без кавычек)
- **Телефон**: всегда с '+' в начале (например: +79991234567)

## Формулы (опционально)

Вы можете добавить полезные формулы для автоматизации:

### Автоматический расчет баланса

В листе `drivers`, можно добавить дополнительную колонку для проверки баланса через сумму транзакций:

```
=SUMIF(transactions!C:C, A2, transactions!E:E)
```

Где A2 - это driver_id текущей строки.

### Подсчет путевых листов за месяц

```
=COUNTIFS(waybills!E:E, A2, waybills!C:C, ">=2024-01-01", waybills!C:C, "<=2024-01-31")
```

## Миграция данных

Если у вас есть существующая база данных водителей:

1. Экспортируйте данные в CSV
2. Импортируйте в Google Sheets (File → Import)
3. Приведите структуру к нужному формату
4. Проверьте типы данных в каждой колонке

---

## Полезные советы

1. **Цвета для статусов**: можно раскрасить строки в листе `drivers`:
   - Зеленый - активные водители (is_active=TRUE)
   - Красный - деактивированные (is_active=FALSE)
   - Желтый - баланс < 100 ₽

2. **Фильтры**: включите фильтры в заголовках для удобного поиска

3. **Условное форматирование**: настройте для автоматической подсветки:
   - Низкий баланс (< 50 ₽) - красный
   - Средний баланс (50-200 ₽) - желтый
   - Хороший баланс (> 200 ₽) - зеленый

4. **Заморозка строк**: заморозьте первую строку с заголовками (View → Freeze → 1 row)
