# Telegram-бот для формирования путевых листов

Проект реализует Telegram-бота для таксопарка. Бот формирует электронные путевые листы (ПЛ), ведёт журнал выпусков и взаиморасчёты с водителями. Постоянные данные хранятся в Google Sheets. Стоимость одного ПЛ — 20 ₽ (можно переопределить для конкретного водителя).

## Основные возможности

- Авторизация водителей по номеру телефона из справочника `drivers`.
- Просмотр баланса и последних операций списаний/пополнений.
- Получение путевого листа в PDF по введённому пробегу с учётом сдвига времени и коррекции одометра.
- Автоматическое списание стоимости ПЛ, фиксация операции в листах `waybills` и `transactions`.
- Генерация стильного PDF-шаблона с данными водителя, авто, медосмотра и механика.

## Архитектура

```
src/
  taxi_bot/
    bot/               # Aiogram-хендлеры, клавиатуры и FSM состояния
    services/          # Интеграции с Google Sheets и генерация PDF
    config.py          # Загрузка настроек из окружения
    models.py          # Структуры данных доменной области
    utils.py           # Утилиты (нормализация телефонов)
templates/
  waybill.html         # HTML-шаблон путевого листа для WeasyPrint
storage/waybills/      # Каталог сохранённых PDF (можно переопределить)
```

## Требования

- Python 3.10+
- Доступ к Google Sheets (сервисный аккаунт с правами «Редактор»)
- Установленные системные зависимости WeasyPrint (libcairo2, pango и т. д.)

## Подготовка окружения

1. Создайте виртуальное окружение и установите зависимости:

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -e .
   ```

2. Скопируйте `.env.example` в `.env` и заполните значения:

   ```bash
   cp .env.example .env
   ```

   Ключевые параметры:

   - `TELEGRAM_BOT_TOKEN` — токен бота от [BotFather](https://t.me/BotFather).
   - `GOOGLE_SERVICE_ACCOUNT_JSON` — путь к JSON-файлу сервисного аккаунта Google.
   - `GOOGLE_SPREADSHEET_ID` — ID таблицы (часть URL).
   - `PDF_STORAGE_DIR` — каталог для сохранения PDF.
   - `PUBLIC_BASE_URL` — (опционально) базовый URL, который будет подставляться к имени файла для ссылок.

3. Создайте сервисный аккаунт в Google Cloud Console и расшарьте на него таблицу.

## Структура Google Sheets

Одна таблица с листами: `drivers`, `waybills`, `transactions`, `settings`.

### `drivers`

| column_id   | Наименование                      | Описание                                     |
| ----------- | --------------------------------- | -------------------------------------------- |
| driver_id   | ID водителя                       | Уникальный идентификатор                     |
| fio         | ФИО                               | Полностью                                    |
| phone       | Телефон                           | Формат +7XXXXXXXXXX                          |
| tg_user_id  | Telegram ID                       | Заполняется ботом                            |
| car_id      | ID авто                           | Опционально                                  |
| car_plate   | Гос. номер                        |                                              |
| car_model   | Марка/модель                      |                                              |
| vin         | VIN                               | Опционально                                  |
| org_name    | Организация/ИП                    | Реквизиты для ПЛ                             |
| med_worker  | Медработник                       | ФИО                                          |
| mech_worker | Механик                           | ФИО                                          |
| last_odo    | Последний пробег                  | Число                                        |
| odo_delta   | Коррекция, Δ км                   | Значение вычитается из введённого пробега    |
| balance     | Баланс, ₽                         |                                              |
| pl_price    | Цена ПЛ                           | Если пусто — берётся значение по умолчанию   |
| tz          | Часовой пояс                      | Например, Europe/Moscow                      |
| is_active   | Активность                        | TRUE/FALSE                                   |

### `waybills`

| column_id     | Описание                               |
| ------------- | -------------------------------------- |
| wb_id         | UUID путевого листа                    |
| wb_number     | Номер ПЛ                               |
| dt_fact       | Фактическое время запроса              |
| dt_print      | Время, указанное в документе           |
| driver_id     | ID водителя                            |
| car_plate     | Гос. номер                             |
| odo_input     | Введённый пробег                       |
| odo_effective | Пробег с учётом коррекции              |
| price         | Списанная сумма                        |
| balance_after | Баланс после списания                  |
| pdf_url       | Ссылка на PDF                          |
| status        | `ok` или `error`                       |
| error         | Текст ошибки (если статус `error`)     |

### `transactions`

| column_id     | Описание                               |
| ------------- | -------------------------------------- |
| tx_id         | UUID операции                          |
| dt            | Дата/время                             |
| driver_id     | ID водителя                            |
| type          | `topup` или `debit`                    |
| amount        | Сумма операции                         |
| reason        | Комментарий                            |
| balance_after | Баланс после операции                  |

### `settings`

Два столбца: `key`, `value`.

Обязательные параметры:

- `waybill_counter` — текущий номер счётчика (число).
- `waybill_number_pattern` — шаблон номера ПЛ (по умолчанию `76-{year}{month}-{counter:04d}`).
- `pl_price_default`, `tz_default`, `time_shift_minutes`, `apply_odo_delta`, `update_last_odo_with` — переопределяют значения из конфигурации (опционально).

## Запуск бота

```bash
python -m taxi_bot.bot.main
```

По умолчанию бот запускается в режиме polling. Для production-среды рекомендуется настроить systemd или Docker для автоперезапуска.

## Тестовые сценарии

1. Авторизуйтесь с телефона, который присутствует в листе `drivers`.
2. Проверьте команду «Мой баланс» и убедитесь, что отображается остаток и последние операции.
3. Выпустите путевой лист — убедитесь, что:
   - баланс уменьшился на стоимость ПЛ;
   - в `waybills` появилась запись со статусом `ok` и ссылкой на PDF;
   - в `transactions` появилась операция `debit` с номером ПЛ.
4. Введите пробег меньше предыдущего — бот предупредит, но позволит продолжить (поведение можно скорректировать в коде).
5. При нулевом или отрицательном пробеге бот выдаст сообщение о неверном значении.
6. При недостаточном балансе выпуск ПЛ блокируется.

## Пример оформления PDF

Шаблон `templates/waybill.html` оформлен в современном стиле с использованием цветового акцента и блоков для водителя, автомобиля, медработника и механика. Для печати используется WeasyPrint, что обеспечивает корректную вёрстку на формате A4.
